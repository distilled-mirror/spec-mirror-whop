# TrackingElement

> Look up a delivery using the order number or tracking number together with the email used at checkout. The element shows native carrier updates and the business’s saved support links. Customer inputs and lookup results stay inside the Whop frame; the hosting website receives none of them. No sign-in or emailed code is required.

> [!NOTE]
>
> This page documents `@whop/elements@1.10.0` and `@whop/elements-react@1.10.0`.

*Since `v1.10.0`.*

Mounts inside [`Delivery`](https://docs.whop.com/elements/latest/delivery/overview). `accountId` comes from there. Pass props and callbacks through the create options or React props.

```tsx React theme={null}
import { WhopElements, Delivery, TrackingElement } from "@whop/elements-react";
import { loadWhop } from "@whop/elements";

function Example() {
  return (
    <WhopElements elements={loadWhop()}>
      <Delivery /* options */>
        <TrackingElement />
      </Delivery>
    </WhopElements>
  );
}
```

```html JavaScript theme={null}
<script src="https://cdn.whop.com/elements/amber/elements.js" data-whop-elements></script>
<script type="module">
  const delivery = window.WhopElements().delivery.create({ /* options */ });
  delivery.create('tracking').mount('#delivery-tracking');
</script>
```

Example data. [Open the Playground](https://docs.whop.com/elements/latest/delivery/overview#playground).

## Props

**showBranding** `boolean`

Follow the saved logo and business-name visibility settings above the form. Set false to omit the entire brand header on a website with its own header. Defaults to `true`.

## Events

Pass callbacks in the create options or React props.

### `onLoaderStart`

Runs after the loading skeleton first paints and before `onReady`.

### `onReady`

Runs after the element's first complete paint.

### `onError`

Runs when the element fails to load or crashes. The fallback remains visible. Use `code` for programmatic handling. `sourceKey` identifies a failed host-state source.

**e** `object`

**properties**

**message** `string` *required*

**code** `string`

**sourceKey** `string`

## Methods

Call these on the handle returned by `create`, or through a React `ref`.

### `mount`

Mounts the element in `target` and starts loading. React components mount themselves.

**Parameters**

**target** `string | HTMLElement` *required*

### `destroy`

Removes the element and releases its frame and subscriptions. You can call it more than once. React removes the element automatically.

### `update`

Merges new props into the mounted element. In React, change the component props instead.

**Parameters**

**options** `Partial\<TrackingElementProps\>` *required*

## Styling

This element doesn't expose class names for styling. Use `appearance` (theme, accent color, variables) to restyle it.

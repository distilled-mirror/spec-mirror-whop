# SearchElement

> A modal for searching messages across the user's channels.

> [!NOTE]
>
> This page documents `@whop/elements@1.10.0` and `@whop/elements-react@1.10.0`.

*Since `v1.10.0`.*

Opens as a modal from [`Chat`](https://docs.whop.com/elements/latest/chat/overview): `chat.createOverlay('search')`. Pass props and callbacks in the create options.

> [!NOTE]
>
> This element is **modal-only**. Open it with `createOverlay`; it has no inline mount.

```tsx React theme={null}
import { WhopElements, Chat, SearchElement } from "@whop/elements-react";
import { loadWhop } from "@whop/elements";

function Example() {
  return (
    <WhopElements elements={loadWhop()}>
      <Chat /* options */>
        <SearchElement onResultClick={(e) => console.log(e)} />
      </Chat>
    </WhopElements>
  );
}
```

```html JavaScript theme={null}
<script src="https://cdn.whop.com/elements/amber/elements.js" data-whop-elements></script>
<script type="module">
  const chat = window.WhopElements().chat.create({ /* options */ });
  chat.createOverlay('search', { onResultClick: (e) => console.log(e) }).open();
</script>
```

## Props

**channelId** `string`

The channel ID to scope search by, prefixed `feed_` or `chat_feed_`. Defaults to the active channel.

**globalSearch** `boolean`

Search across all the user's channels. Defaults to `false`.

## Events

Pass callbacks in the create options or React props.

### `onResultClick`

Emitted when the user clicks a search result. Call `close()` on the overlay to dismiss the modal.

**payload** `object`

**properties**

**messageId** `string` *required*

**channelId** `string` *required*

### `onLoaderStart`

Runs after the loading skeleton first paints and before `onReady`.

### `onReady`

Runs after the element's first complete paint.

### `onError`

Runs when the element fails to load or crashes. The fallback remains visible. Use `code` for programmatic handling. `sourceKey` identifies a failed host-state source.

**e** `object`

**properties**

**message** `string` *required*

**code** `string`

**sourceKey** `string`

## Methods

Call these on the handle returned by `create`, or through a React `ref`.

### `mount`

Mounts the element in `target` and starts loading. React components mount themselves.

**Parameters**

**target** `string | HTMLElement` *required*

### `destroy`

Removes the element and releases its frame and subscriptions. You can call it more than once. React removes the element automatically.

### `update`

Merges new props into the mounted element. In React, change the component props instead.

**Parameters**

**options** `Partial\<SearchElementProps\>` *required*

## Styling

This element doesn't expose class names for styling. Use `appearance` (theme, accent color, variables) to restyle it.
